The job

Non-streaming speech-to-text asks how accurately a model turns a finished audio file into text (word error rate on final transcripts). Lower WER is better. It is not an LLM chat or coding score, and it is a different Index from streaming STT (chunk-by-chunk live audio).

What changed

Zoom Scribe V2 Pro appears on AA’s board for the first time at 2.8% — tied mid-pack on the display with Gemini 3.1 Pro Preview (High) and Voxtral Small, well behind the 1.7% leaders. Use it as a product STT read, not as a new frontier LLM audit.

Where they land

    Don’t mix harnesses: Agent Arena Net Improvement ≠ Elo and ≠ pass-rate agent benches. LMArena Text/Vision Elo ≠ accuracy %. LMArena WebDev Elo ≠ Vibe Code Bench. LMArena Image-to-WebDev ≠ WebDev Elo (different task). AA non-streaming WER ≠ streaming WER (different Index). AA Terminal-Bench 4.0 ≠ Vals TB 4.0 mini-swe-agent ≠ Anthropic vendor TB 4.0. Streaming WER is lower-better and not an LLM score. Epoch ECI ≠ AA Intelligence Index: different scales, don’t blend. Alignment Index ≠ Agent Net Improvement. LAB-AA v1.1 ≠ v1.0. Trusted-access Cyber ≠ public Cyber. Scale HSS ≠ LMArena Vision Elo. CyberGym-E2E-AA is one of three parts of the AA Cyber Index, so don’t read them as two separate wins. LMArena image Elo ≠ Google’s internal model-card Elo.

    OpenAI misalignment report. Self-reported Alignment page (incident Oct 6; updated Oct 9). Sandbox, not live systems; heavily redacted; no model named; no rate beyond “generally low.” Transcript “does not establish how much of the filesystem” was deleted. Lean confirms proof validity, not that the formal statement matches the informal problem (Avigad & Ballard Perspective). Natural-language proofs written by human co-authors from agent drafts.
