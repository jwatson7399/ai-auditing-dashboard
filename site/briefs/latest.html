Read before trusting

Noise floor. About 1–3 points on percentage indexes is noise. Small Elo gaps are soft without CI bands.

Effort ≠ chat default. Charts use high/xhigh/max. Your app default is usually lower and cheaper.

Harness matters. Coding Agent Index compares native agents (Grok Build, Claude Code, Codex). Intelligence Index uses a unified harness — do not mix them.
