Read before trusting

Three-point rule. Differences of one to three points are within the noise of these tests. Cards say "within noise" when the top two are that close.

Testers disagree. The same named test run by two testers on different harnesses can reach opposite conclusions. The picks use Artificial Analysis numbers only; other testers' figures appear in the Scout section and are never blended in.

Preference votes are not task tests. Frontend, image, video, and writing are ranked by blind human votes (which output do people prefer). That is real signal but it measures taste, not whether the job got done. Cards say which kind of evidence they rest on.

Effort settings. Benchmark charts use each model's best effort setting, and that setting is stored with every score. Your app's default is usually lower. The effort table shows how much that matters.

Index versions are not comparable. Artificial Analysis revises its Intelligence Index. Scores from different versions are not comparable, so the version is shown with the effort table.

Access assumptions. Image and video products are matched to subscriptions by name; confirm what you actually see in each app. A newly released model may be listed before it reaches your app, in which case use the runner-up.

News is unverified. The Verifier checks benchmark quotes only. Nobody independently checks the news links, so treat the stories above as reported, not confirmed.

Stale sources are labeled. When a source could not be refreshed, the page shows the last numbers it had with the date they were fetched, and the status line says so.
